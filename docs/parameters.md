# 参数索引

| 服务 | 参数或行为 | 目标文件 | 函数或定位依据 | 值及单位 | 验证状态 |
| --- | --- | --- | --- | --- | --- |
| 夸克网盘 | `exp_svip` 未识别时涉及的上传上限 | `/usr/bin/autopanel`，见[构建哈希](install.md) | 会员类型线索为 `exp_svip`，函数名及分支待核对 | 待由原分析或二进制确认 | 用户已在原环境验证修复 |

修复文件的默认路径含有 `test16g`。目录名只能作为回查线索，数值与单位需要用原始定位证据确认。当前脚本没有提供其他参数的名称或位置。

## 新增参数条目

| 字段 | 应填写的内容 |
| --- | --- |
| 参数 | 所属服务、参数名称、影响的行为 |
| 构建 | 版本、平台、架构、目标文件路径、原文件和 Ghidra 导入文件的 SHA-256 |
| 定位 | 函数名或地址、字符串交叉引用、调用关系、具体分支 |
| 数值 | 原值、改后值、精确单位、适用条件 |
| 验证 | 静态定位或运行验证，并附测试输入和结果 |

新版本若无法复用同一定位，单独记录该版本的文件哈希、函数地址和判断分支。
